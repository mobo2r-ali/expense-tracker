Expense Tracker 💰

A simple command-line Expense Tracker built with Python. It helps users record expenses, view their spending history, calculate total expenses, and track spending by category.

Features

- Add new expenses
- View all recorded expenses
- Calculate total expenses
- View expense summaries by category
- Save expense data in a CSV file
- Validate user input
- Display colored terminal menus

Technologies Used

- Python
- CSV
- Colorama
- Git & GitHub

Installation

1. Clone the repository:
   
   git clone git@github.com:mobo2r-ali/expense-tracker.git

2. Navigate to the project directory:
   
   cd expense-tracker

3. Install the required dependency:
   
   pip install -r requirements.txt

Usage

Run the application:

python main.py

Follow the menu instructions to manage your expenses.

Data Storage

Expenses are stored locally in "expenses.csv".

This file is excluded from Git to keep personal expense data private.
